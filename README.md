# 坂道TD (SakamichiTD)
### 縦型転がりラインディフェンス × ローグライト（手描きスケッチ準拠・改訂版プロトタイプ）

「見た目はコロコロ気持ちよく板の上を転がっているが、内部ロジックは安定した一本道のラインバトル」として完全リニューアルされたゲームプロトタイプです。

手描きスケッチに忠実に、**右上（自陣ゲート）から板（スロープ台）をコロコロ転がり落ちていき、左下（敵要塞）から板を登ってくる敵軍と一本道の上で正面衝突**するステージ構成になっています。

## 🪵 ステージ構成（手描きスケッチの完全再現）

1. **右上: 自陣ゲート（投入口）**
   - 漏斗/ホッパー型の投入口からボールを出撃。板1に乗って左へ滑走開始！
2. **板1（最上段スロープ）**:
   - 右上から左へ傾斜した木製の板。ボールは板の上を左へ転がり下る（反時計回り自転）。
3. **ターン1（左端折り返し）**:
   - 板1の左端から板2の左端へ弧を描いてスムーズに転落・転入！
4. **板2（中段スロープ）**:
   - 左から右へ傾斜した木製の板。ボールは板の上を右へ転がり下る（時計回り自転）。
5. **ターン2（右端折り返し）**:
   - 板2の右端から板3の右端へスムーズに転落・転入！
6. **板3（下段スロープ）**:
   - 右から左へ傾斜した木製の板。ボールは板の上を左下の敵陣へ向かって転がり下る。
7. **左下: 敵要塞（三角屋根タワー）**:
   - スケッチ通りの大きな三角屋根を持つ敵の要塞。敵軍歩兵がここから板を上って進軍してきます。

## 🌟 新機能: 渋滞解消 ＆ マージ合体進化システム (スイカゲーム風)

「一番前のボールしか戦えず渋滞してしまう」問題を解決するため、2大進化システムを実装！

### 1. 前線重なり合い ＆ 全員ポコポコ一斉攻撃（にゃんこ大戦争スタイル）
- ボール同士が前線でギュッと重なり合えるようになり、数珠つなぎの渋滞を解消。
- **前線に到達した味方ボールは全員が攻撃サイクルに参加し、敵を一斉にタコ殴り**にします！ボールをたくさん流すほど圧倒的な大乱闘と高い総攻撃力（DPS）が発揮されます。

### 2. 同種ボール ＆ 敵のマージ合体進化（スイカゲーム風）
- 同じ種類のボール同士が接近・重なると「ポヨン！」と合体してレベルアップ！
  - **Lv.1**: 通常サイズ・基本性能
  - **Lv.2 (★)**: サイズ1.3倍、HP合算＋体力全快、攻撃力1.8倍、押し出しパワー+2
  - **Lv.3 (★★ MAX)**: サイズ1.7倍、HP合算、攻撃力3.0倍、押し出しパワー+4！
  - **ボムボール** がマージすると、画面半分を覆い尽くす超巨大ギガ爆破に進化！
- **敵軍もマージ合体**: 敵も同種が重なると「★ELITE」に合体して巨大化するため、前線が常にダイナミックに変化します！
